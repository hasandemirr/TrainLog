## 5. Sahip adımı — göçü gerçek veriyle yerelde koş (D49)

Gerçek `antrenman.v1` yedeğini JSON olarak `local-data/`'a koy (gitignore'da). Geçici bir yerel test ile (repoya girmeden) koş:

```ts
// local-data/_migrate-check.test.ts  (yerelde tut; commit etme)
import { readFileSync } from 'node:fs';
import { migrateV1 } from '../src/domain/migrate';
import { isAppState } from '../src/domain/validate';
// realSeed: gerçek programını yansıtan SeedCatalog (elle ya da S2 tohumundan)
const v1 = JSON.parse(readFileSync('local-data/backup.json', 'utf8'));
const out = migrateV1(v1, realSeed, { now: Date.now(), idgen: () => crypto.randomUUID() });
console.log(Object.keys(out.sessions).length, 'seans;', Object.keys(out.records).length, 'kayıt');
if (!isAppState(out)) throw new Error('geçersiz v2');
```

`npx vitest run local-data/_migrate-check.test.ts` → yeşilse göç gerçek veride sağlam. Sonra dosyayı sil. Repoya yalnızca sentetik fixture girer.
